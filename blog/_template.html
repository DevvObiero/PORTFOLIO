Your Post Title

One or two sentences that sum up the post. Shown in search results, share cards and the blog home page.

31 January 2026 · 5 min read

Start with a short intro paragraph that tells the reader what the post is about and why it matters. Paragraphs are ordinary <p> tags. Links look like this, and bold text uses <strong>.

A section heading

Use <h2> for each main section of the post.

A smaller heading inside a section

Use <h3> under an <h2>. Don't skip levels (no <h3> straight after the title).

  • A bullet list uses <ul> and <li>.
  • Each item gets a thin dash instead of a dot.
  1. A numbered list uses <ol>.
  2. Numbers show as 01, 02, 03, like the cards.

A quote goes inside <blockquote>.

Inline code like posts.js uses <code>. Code blocks look like this:

const greeting = "Hello from the template";
console.log(greeting);

Wrapping up
